YBCO pellets, Tc taken as the midpoint of the resistive transition.
Fast cool (quenched from 900 C): runs 1 to 3, Tc = 89.1, 89.6, 88.9 K. Mean 89.2 K.
Slow cool (2 C/min from 900 C in flowing oxygen): runs 4 to 6, Tc = 91.0, 90.6, 91.3 K. Mean 91.0 K.
All six pellets pressed from the same powder batch.
Pt100 thermometer recalibrated against the reference diode between run 3 and run 4. The offset changed by 1.2 K; I didn't write down which direction.
Spread within each group about 0.7 K.
Idea: slow cooling in oxygen raises the oxygen content, so Tc goes up.
